# 规范申报要素

> 来源：《中华人民共和国海关进出口商品涉税规范申报目录》（年度版）
> 注意：具体字段以各HS编码的法定申报要素为准，以下为通用指南

---

## 一、申报要素类型

### 归类要素
影响HS编码归类的技术参数，例如：
- 用途、功能、工作原理
- 材质、成分含量、加工方法
- 品牌类型
- 出口享惠情况
- 显示/播放原理
- 控制方式

### 价格要素
影响完税价格认定的商业信息，例如：
- 品牌（中文或外文名称）
- 型号
- 签约日期
- 计价方式

### 其他要素
特殊要求，例如：
- 中韩自贸协定项下数控装置品牌
- ECFA项下原产地信息
- 特许权使用费

## 三、品牌类型申报

| 代码 | 含义 |
|------|------|
| 0 | 无品牌 |
| 1 | 境内品牌 |
| 2 | 境外品牌（贴牌生产） |
| 3 | 境外品牌（其他） |

## 四、出口享惠情况

| 代码 | 含义 |
|------|------|
| 0 | 出口不涉及优惠贸易协定 |
| 1 | 出口涉及优惠贸易协定且可享受协定税率 |
| 2 | 出口涉及优惠贸易协定但不可享受 |

## 五、申报要素整理步骤

1. 确定10位HS编码
2. 通过单一窗口或规范申报目录查询该编码的法定申报要素字段
3. 逐字段填写（从产品资料/用户提供的信息中提取）
4. 区分标注���已确认/待确认
5. 缺失字段填"待确认：______"

**绝对禁止**：编造申报要素内容、用示例字段替代法定字段

## 六、常见申报要素对应的技术信息

| 申报要求 | 需要从产品资料提取的信息 |
|---------|---------------------|
| 用途 | 家用/商用/工业/医疗等 |
| 功能 | 产品的核心功能描述 |
| 工作原理 | 技术实现方式（如DLP/激光/电磁感应等） |
| 材质 | 主要构成材料 |
| 成分含量 | 合金成分/化学成分比例 |
| 品牌 | 产品标注的品牌名称 |
| 型号 | 制造商型号 |
| 电压 | V（伏特） |
| 功率 | W（瓦特） |
| 容量 | mAh/Wh/升等 |
| 是否含电池 | 是/否，类型和参数 |
| 是否含无线功能 | 是/否，WiFi/蓝牙/其他 |
| 整机/零件 | 完整设备or部件or附件 |

### 明细版（供内部审核）
| 序号 | 申报字段 | 申报内容 | 信息来源 | 状态 |
|------|---------|---------|---------|------|

---

## 八、注意事项

1. 申报要素字段以该HS编码的法定要求为准，不同编码字段不同
2. 不要用其他相似编码的字段替代
3. 具体申报要素目录每年更新，需使用当年版本
4. 可通过单一窗口申报环节查看最新申报要素要求
5. 部分特殊贸易方式申报要素可能简化（需以当地海关要求为准）
