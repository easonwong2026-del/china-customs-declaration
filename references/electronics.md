# 电子产品归类参考

> 覆盖：投影仪、电视、显示器、音响、回音壁、低音炮、功放、电脑配件、电源适配器、遥控器、显示模组、无线模块、锂电池、带电池电子产品等

---

## 一、投影仪

| 属性 | 内容 |
|------|------|
| 品目 | 85.28 |
| 可能子目 | 8528.62（ADP专用）/ 8528.69（其他）/ 8528.72（电视投影设备） |
| 关键区分 | 是否有HDMI等通用接口 → 通常8528.69 |
| 含TV调谐器 | → 8528.72（电视投影设备—含电视接收功能） |
| 显示技术 | DLP/LCD/LCoS/Laser，不改变子目 |
| 常见误归类 | 9007.20（电影放映机—仅专业影院用） |
| 分辨率 | 不改变HS编码 |

**归类判断流程**：
```
含电视接收功能？
 ├── 是 → 8528.72
 └── 否 → 仅用于ADP系统？
            ├── 是 → 8528.62
            └── 否 → 8528.69
```

## 二、电视/显示器

| 属性 | 内容 |
|------|------|
| 电视（含调谐器） | 8528.72 |
| 显示器（仅ADP用） | 8528.52 |
| 其他显示器 | 8528.59 |

**关键区分**：
- 有TV调谐器 = 电视
- 仅有DisplayPort/HDMI，仅用于ADP系统 = 8528.52
- 多信号源接口 = 8528.59

## 三、音响/扬声器

| 属性 | HS子目 | 备注 |
|------|--------|------|
| 单扬声器（有源） | 8518.21 | 单个驱动单元装在箱体内 |
| 多扬声器（同一音箱） | 8518.22 | 多个驱动单元装在同一个箱体内 |
| 其他扬声器 | 8518.29 | 不在上述范围的扬声器 |
| 音频放大器 | 8518.40 | 独立功放 |
| 电气扩音机组 | 8518.50 | 成套扩音系统 |
| 耳机/耳塞 | 8518.30 | |

**回音壁归类**：
- 多个扬声器单元在同一长条形音箱内 → 8518.22
- 含D类功放但内置 → 仍在8518
- 含低音炮套装 → 按成套归类
- 含独立外置功放 → 可能8518.50

**低音炮归类**：
- 有源低音炮（含功放）→ 8518.29
- 无源低音炮 → 8518.29
- 如与回音壁作为套装 → 随主机归类

## 七、激光光源模块/显示芯片/显示模组

| 类型 | 归类方向 |
|------|---------|
| 激光光源模块（投影仪用） | 9013.20（激光器）或按投影仪零件归类 |
| DMD/DLP显示芯片 | 8541（半导体器件）或按投影仪零件 |
| LCD/LED显示模组 | 8524（平板显示模组）/ 9013 |
| 通用零件 | 按材质/功能分别归类 |
| 专用零件 | 随整机归类（如仅为某型号专用） |

**判断逻辑**：
```
是否为投影仪/电视/显示器的专用零件？
 ├── 是 → 除非另有规定，随整机归类（如8529.90、9013.90等）
 └── 否 → 按自身属性归类
```

## 九、锂电池

| 情景 | HS编码 |
|------|--------|
| 独立进口（锂离子） | 8507.60 |
| 嵌入设备（不可拆卸） | 随整机归类 |
| 锂金属一次电池 | 8506.50 |

**合规要求**：
- CCC认证：2024年8月1日起
- 运输：UN38.3 + MSDS + 危包证
- 出口管制：≥300Wh/kg需商务部出口许可（2025年11月8日起）

## 十、带电池电子产品

| 原则 | 说明 |
|------|------|
| 主归类 | 电池不改变产品主要功能归类 |
| CCC | 整机+电池均需满足CCC（如在目录内） |
| 运输 | UN3481（电池装在设备中）/ UN3171（电池驱动车辆） |

## 常见归类错误

1. **投影仪归入9007.20**：9007.20是电影放映机，仅用于专业影院
2. **显示器归入8528.52**：只有"仅用于ADP系统"的才归8528.52
3. **回音壁归入8519**：8519是声音录制/重放设备（如CD机），不是扬声器
4. **蓝牙音箱归入8517**：通信功能是辅助的，主要功能是音频播放
5. **所有投影仪零件归入8529.90**：需确认是否"专用于"该设备
