# 动态数据核实指南

> **重要**：本文件中的数据项在执行任务时必须实时查询。
> 不得将本文件中的任何示例数据视为永久有效。

---

## 必须实时查询的数据项

### 1. HS编码
- 当前年度税则是否有调整
- 10位编码是否仍然有效
- 是否存在拆分/合并

### 2. 税率
- 最惠国税率（MFN）
- 暂定税率（如有，需对应用途/条件）
- 协定税率（如有FTA且凭原产地证）
- 特惠税率（原产国为LDC）
- 普通税率（非WTO成员）
- 增值税率（一般13%，部分9%）
- 是否涉及加征关税/反倾销/反补贴

### 3. 监管条件
- A/B/O/1/3/4等代码对应的具体要求
- 是否需要办理相关许可证/通关单

### 4. 法定检验检疫
- 是否在法检目录
- 检验检疫代码（M/N/R/S/P/Q等）

### 5. CCC认证
- 是否在CCC目录
- 证书状态/免办可能性

### 6. SRRC
- 是否含无线电发射功能
- 是否需要型号核准
- 模块是否已有认证

### 7. 出口管制
- 是否在两用物项管制清单
- 是否需要出口许可证

### 8. 贸易救济措施
- 反倾销、反补贴、保障措施

---

## 查询方法

### 单一窗口 HS编码查询
1. 进入 singlewindow.cn
2. 使用"通关参数"功能
3. 输入10位HS编码
4. 获取：税率、监管条件、检验检疫代码、法定单位

### 海关总署 政策查询
1. 进入 customs.gov.cn
2. 使用"海���法规"或"政策解读"
3. 搜索相关公告号或商品名称

### 商务部 许可证查询
1. 进入 mofcom.gov.cn
2. 查询最新许可证管理目录
3. 确认商品是否在目录内

每次查询后应记录：
```
查询项目：进口关税税率
HS编码：8528.6900.00
原产国：日本
查询日期：YYYY-MM-DD
查询来源：单一窗口
结果：[税率值]
备注：[任何附加说明]
```

## 版本追踪

- 税则版本：当前年度 + 最近公告号
- 关税方案：年度公告号
- 规范申报目录：年度版本
- 许可证目录：商务部年度公告
- CCC目录：认监委最新公告
