# 监管合规风险

> 覆盖：CCC认证、SRRC、法检、许可证、知识产权、危险品等

---

## 一、CCC认证（中国强制性产品认证）

### 需要CCC认证的电子产品大类
- 音视频设备（08类）
- 信息技术设备（09类）
- 照明电器（10类）
- 电信终端设备（16类）
- 锂电池和移动电源（2024年8月1日起）

### CCC判断流程
```
1. 查产品是否在CCC目录内
2. 在目录内 → 是否有CCC证书？
   ├── 有 → 申报时填写证书号（许可证代码411）
   └── 无 → 可否办理CCC免办？
          ├── 可（科研/维修/展示/整机出口等）→ 申请免办证明（代码409）
          └── 不可 → 禁止进口
3. 不在目录内 → 申报时选择"3C目录外"（代码12）
4. 无需办理情形 → "无需办理3C认证"（代码13）
```

### CCC免办条件
1. 科研、测试和认证检测所需的产品和样品
2. 直接为最终用户维修目的所需的零部件
3. 工厂生产线成套生产线配套所需的设备零部件
4. 仅用于商业展示但不销售的产品
5. 以整机全数出口为目的进口的零部件
6. 其他因特殊用途免予办理的情形

### 无需办理CCC的情形
- 暂时进出口货物
- 外交人员自用物品
- 入境人员随身携带物品
- 政府间援助赠送物品
- ATA单证册商品
- 入保税区货物
- CCC型式试验样品
- 出口后退运入境货物

## 二、SRRC（无线电发射设备型号核准）

### 适用范围
含无线电发射功能的设备，包括但不限于：
- WiFi（2.4GHz/5GHz/6GHz）
- 蓝牙（经典+BLE）
- ZigBee、Z-Wave、LoRa
- 2.4G私有协议
- NFC
- 蜂窝通信模块（2G/3G/4G/5G）

### 豁免范围
- 微功率短距离设备（需符合国家规定）
- 部分极低功率设备

### 进口要求
- 须取得《无线电发射设备型号核准证》
- 报关时海关可能要求提供证书
- 证书有效期不超过5年

### 注意
- 使用已认证模块的整机仍可能需要单独认证
- 天线设计变更可能需要重新认证
- 临时进出口可申请临时进关批准文件（有效期6个月）

## 三、法定检验检疫

### 法检目录
- 海关总署发布《出入境检验检疫机构实施检验检疫的进出境商品目录》
- 监管条件代码A=入境货物通关单（进口法检）
- 监管条件代码M=进口商品检验
- B=出境货物通关单（出口法检）

### 电子产品法检关注点
- 是否在法检目录内
- 安全项目（电气安全、机械安全）
- 电磁兼容（EMC）
- 能效标识（部分产品）

## 四、危险品（锂电池相关）

### 运输要求
| 项目 | 要求 |
|------|------|
| UN38.3测试 | 必须（含摘要） |
| MSDS | 中英文，16项完整 |
| 危包证 | 性能单+使用鉴定单 |
| UN编号 | UN3480（独立）/ UN3481（含设备） |
| 危险品类别 | Class 9 |
| 空运电量限制 | ≤30% SoC（2026年起扩展适用） |
| 标签 | 9类危险品标签 + 锂电池专用标记 |

## 五、进出口许可证

### 自动进口许可证（O证）
- 部分机电产品需要
- 商务部发布年度目录
- 凭编码"O"在单一窗口申报

### 进口许可证（1证）
- 重点旧机电产品
- 消耗臭氧层物质
- 商务部发布年度目录

### 出口许可证（4证）
- 特定商品需要
- 商务部发布年度目录

### 两用物项出口许可证（3证）
- 两用物项和技术出口管制清单内产品
- 含特定技术的电子产品可能需要
- 2025年11月8日起：≥300Wh/kg的高能锂离子电池需出口许可

## 六、知识产权海关保护

### 备案制度
- 注册商标、著作权、专利权可在海关总署备案
- 备案有效期10年
- 办理不收取费用

### 保护模式
**依职权保护**（主动）：海关发现涉嫌侵权货物时主动中止放行
**依申请保护**（被动）：权利人发现侵权货物申请海关扣留

### 进出口申报注意事项
- 出口使用他人品牌需有品牌授权书
- 品牌已在海关备案的需如实申报知识产权状况
- 假冒侵权货物将被没收、处罚

## 七、风险分级速查表

| 风险等级 | 典型场景 | 可能后果 |
|---------|---------|---------|
| **严重** | 缺少CCC/许可证/SRRC | 退单/扣货/处罚 |
| **严重** | HS编码错误 | 补税/处罚/改单 |
| **严重** | 品牌侵权未授权 | 扣货/没收/处罚 |
| **严重** | 锂电池未按危险品申报 | 退运/安全事故 |
| **中等** | 申报要素不完整 | 查验/补资料 |
| **中等** | 品名过于宽泛 | 审单质疑 |
| **中等** | 价格异常偏低 | 审价/补税 |
| **中等** | 单据间不一致 | 审核/改单 |
| **提醒** | 格式不规范 | 建议改进 |
| **提醒** | 英文品名拼写建议 | 建议修正 |
