## 三、单据一致性检查

### 跨单据字段比对
| 字段 | 合同 | 发票 | 箱单 | 报关单 | 必须一致？ |
|------|:----:|:----:|:----:|:------:|:--------:|
| 品名 | ✓ | ✓ | ✓ | ✓ | **是** |
| 型号 | ✓ | ✓ | ✓ | ✓ | **是** |
| 数量 | ✓ | ✓ | ✓ | ✓ | **是** |
| 总价 | ✓ | ✓ | ✗ | ✓ | **是** |
| 币种 | ✓ | ✓ | ✗ | ✓ | **是** |
| 毛重 | ✗ | ◯ | ✓ | ✓ | **是** |
| 净重 | ✗ | ◯ | ✓ | ✓ | **是** |
| 件数 | ✗ | ✓ | ✓ | ✓ | **是** |
| 原产国 | ◯ | ✓ | ✗ | ✓ | **是** |
| 品牌 | ◯ | ✓ | ✗ | ✓ | **是** |
| HS编码 | ✗ | ✓ | ✗ | ✓ | **是** |
| 包装 | ✗ | ◯ | ✓ | ✓ | **是** |

✓ = 应一致 | ◯ = 通常一致 | ✗ = 不要求

### 计算校验
1. 单价 × 数量 = 总价（每项）
2. Σ(分项总价) = 发票总额
3. 毛重 ≥ 净重（每项及合计）
4. Σ(分项净重) = 总净重
5. 件数 = Σ(箱数)
6. 发票总额 与 合同金额 一致

### 归类一致性检查
1. 相同型号 → 相同HS编码
2. 不同型号 → 确认是否应不同编码
3. 相同HS编码 → 申报要素结构应一致
4. 申报要素内容 → 与HS编码的法定要求匹配

## 四、常见问题及风险等级

| 问题 | 风险等级 |
|------|---------|
| 发票和箱单品名不一致 | **严重** |
| 数量不符（跨单据） | **严重** |
| HS编码与申报要素不匹配 | **严重** |
| 总价计算错误 | **严重** |
| 毛重<净重（物理不可能） | **严重** |
| 币种不一致（跨单据） | **中等** |
| 型号缺失 | **中等** |
| 品名过于宽泛（如"电子产品"） | **中等** |
| 品牌缺失 | **中等** |
| 重量数值异常 | **中等** |
| 英文品名拼写错误 | **提醒** |
| 格式不规范 | **提醒** |

## 五、报关单关键字段

### 表头信息
- 进出口口岸
- 运输方式
- 贸易方式
- 征免性质
- 结汇方式
- 许可证号
- 起运国/运抵国
- 成交方式
- 运费/保费/杂费
- 件数/包装种类
- 毛重/净重
- 集装箱号

### 表体信息（每项商品）
- 项号
- 商品编号（HS编码）
- 商品名称（规范品名）
- 规格型号（申报要素在此）
- 数量及单位（法定单位+��交单位）
- 原产国/最终目的国
- 单价/总价/币种
- 征免（征税/免税/全免等）
