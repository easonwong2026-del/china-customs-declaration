# HS商品归类工作流程

> 来源：税则归类总规则 + 商品归类管理规定（海关总署令第252号）
> 稳定程度：高（归类总规则相对稳定，WCO每5年左右修订HS）

---

## 一、归类总规则速查

### 规则一：品目条文+类注章注优先
货品按品目条文和有关类注或章注确定归类。
类、章标题仅为查找方便，**不具有法律效力**。

### 规则二（一）：不完整品/未制成品
具有完整品基本特征的不完整品，按完整品归类。
未组装件/拆散件按已组装品归类。

### 规则二（二）：混合/组合材料
列出某种材料的品目包括该材料与其他材料的混合物。
由一种以上材料构成的货品按规则三归类。

### 规则三（一）：具体列名优先
列名具体的品目优先于列名一般的品目。

### 规则三（二）：基本特征
混合物、组合物、成套货品按构成基本特征的材料/部件归类。

### 规则三（三）：从后归类
无法按（一）（二）归类时，归入号列顺序最后的品目。

### 规则四：最相类似
无法按规则一至三归类时，归入最相类似的品目。

### 规则五：容器/包装
专用容器与所装物品一并归类。
普通包装与货品一并归类（可重复使用的除外）。

### 规则六：子目归类
子目归类比照规则一至五，同级的子目才能比较。

## 二、电子产品归类六步法

### Step 1: 商品本质判断
- 该商品是什么？（不要被名称误导，看本质功能）
- 输入什么？输出什么？

### Step 2: 主要功能判断
- 多功能设备：哪个功能是主要功能？
- 组合设备：哪部分是核心功能？
- 零售成套货品：哪件构成基本特征？

### Step 3: 材质和成分判断
- 外壳材质不影响归类（电子产品按功能归类）
- 内部核心元件类型影响归类

### Step 4: 工作原理判断
- 机械原理 → 84章
- 电气/电子原理 → 85章
- 光学/声学 → 相应品目

### Step 5: 加工程度判断
- 整机 vs 零件 vs 附件
- 专用零件随整机归类（有例外）
- 通用零件按材质归类

### Step 6: 章节定位
- 初步判断章节 → 阅读类注 → 阅读章注 → 阅读子目注释
- 对比候选编码 → 排除 → 确定建议编码

## 三、第十六类（84-85章）关键类注

### 类注二：零件归类
除本类注释一、第八十四章注释一及第八十五章注释一另有规定外：
- 专用于或主要用于某一种机器的零件，与该机器一并归类
- 能同时主要用于多种机器的零件归入84.87或85.48

### 类注三：组合机器/功能机组
组合机器按主要功能归类。
功能机组（通过管道、电缆等连接的整体）按整体功能归类。

### 类注四：附属装置
附属的互换性零件或装置，如果专用于某种机器且通常与其一同报验，可按该机器归类。

## 四、商品归类信息不足处理

### 触发条件
任何一个P0信息项缺失，即触发。

### 标准处理流程
```
1. 列出当前已确认的信息
2. 标注每条信息的来源（产品规格书第X页/用户描述等）
3. 识别信息缺口
4. 生成不超过10个具体问题
5. 根据已有信息给出候选方向（标注置信度：低）
6. 标注归类风险
```

### 标准问题模板

**功能/用途确认类**：
- 产品的主要功能是什么？是否有多项功能？哪项是主要功能？
- 产品的主要用途是什么（家用/商用/工业/医疗）？

**技术参数类**：
- 使用什么显示/处理/通信技术？
- 工作电压/功率/容量是多少？
- 核心元件或模块是什么？

**功能特性类**：
- 是否含无线功能（WiFi、蓝牙、其他）？
- 是否含电池（类型、容量、是否可拆卸）？
- 是否含电视接收/收音机/GPS等功能？

**状态属性类**：
- 产品是整机还是零部件/附件？
- 是否为新品？是否为样品？是否为旧品？
- 产品是否已组装或为散件？

**贸易背景类**：
- 是否有历史进口/出口记录或历史HS编码？
- 是否有海关预裁定或归类决定？
- 原产国/最终目的国是哪里？

## 五、归类预裁定指南

### 适用情形
- 归类存在较大争议
- 商品将长期、大量进出口
- 涉及较高关税或贸易管制

### 申请条件
- 在货物拟进出口**3个月前**提出
- 向**注册地直属海关**申请
- 通过"单一窗口"或"互联网+海关"在线提交

### 申请材料
1. 预裁定申请书
2. 合同/订单/意向书
3. 商品描述（规格型号、材质、成分、结构、工作原理、功能、用途）
4. 保密声明
5. 材料为外文的需中文译本

### 办理时限
- 海关10日内决定是否受理
- 受理后60日内作出决定
- 有效期3年

## 六、归类陷阱提醒

1. **不要凭品名归类**：同样的品名可能对应不同功能的产品
2. **不要忽略类注章注**：类注章注中常有排除条款
3. **不要忽视多用途**：含HDMI等通用接口通常不是ADP专用
4. **不要混淆整机和零件**：专用零件随整机，通用零件独立归类
5. **不要忽略版本**：每年税则可能调整子目
6. **不要忽略本国子目**：前6位国际相同，后4位为中国特有
