# 案例处理参考

> 案例来源于公开的归类决定、预裁定和行业经验分析
> 所有企业/品牌/价格信息已脱敏
> 仅供参考，不代表海关最终认定

---

## 案例一：家用激光投影仪

- **建议编码**：8528.6900.00
- **排除编码**：8528.62（非仅ADP专用）、8528.72（无电视调谐器）、9007.20（非电影放映机）
- **归类逻辑**：HDMI接口可连接多种信号源 → 非仅用于ADP → 8528.69
- **风险点**：SRRC（WiFi/蓝牙）、CCC（音视频设备）
- **待确认**：是否含智能操作系统影响归类

## 案例二：回音壁+无线低音炮套装

- **建议编码**：8518.2200.00
- **归类逻辑**：多扬声器在同一音箱内 + 低音炮作为成套货品随主机
- **风险点**：SRRC、CCC、分装申报问题
- **待确认**：低音炮是否独立包装/计价

## 案例三：锂电池（独立进口）

- **建议编码**：8507.6000.90
- **风险点**：CCC（2024年8月起）、UN38.3、危险品运输、≥300Wh/kg出口管制
- **待确认**：能量密度Wh/kg

## 案例四：便携蓝牙智能音响

- **建议编码**：8518.21/8518.22（根据扬声器数量）
- **归类逻辑**：音频播放为主功能，语音助手为辅助
- **风险点**：SRRC、CCC、锂电池运输

## 案例五：三星回音壁多型号批次 + 无线后置扬声器套件（2026-07）

- **批次构成**：3款回音壁（Q990H 11.1.4ch 含低音炮+后置 / QS90H 7.1.2ch 一体式 / HW-QS700F 3.1.2ch）+ 1款无线后置扬声器套件（SWA-9250S），合计205台，分7托盘报验（其中HW-QS700F 4托盘×20台）
- **建议编码**：
  - 回音壁（多扬声器单元同一长条音箱，含内置功放/低音炮/解码/无线）→ **8518.2200.00**（中-高）
  - 无线后置扬声器套件（独立报验的一对后置音箱+无线接收模块）→ **8518.2200.00 或 8518.2900.00**（中）；候选①按成对多单元音箱归8518.22，候选②按成套件归8518.29，建议预裁定确认
- **归类逻辑**：主要功能为声音重放；含HDMI/蓝牙/WiFi/解码/功放不改变扬声器归类；**不归** 8519（声音录放设备）、8517（通信设备）、8521（视频信号重放设备）
- **多托盘聚合**：同一型号分多托盘报验时，按商品（货号）聚合为1项申报，HS不因子票拆分而改变
- **申报要素（8518.22/8518.29）**：品牌类型；出口享惠情况；用途；品牌；型号；声道数/扬声器数量；是否含放大器；额定功率
- **风险点**：SRRC（蓝牙/WiFi，进口内地需型号核准）；CCC（8518属08类音视频设备目录，进口内地需证书，出口香港可办免办409/无需办理13）；木质托盘IPPC熏蒸；三星为备案品牌需授权；电池需确认（回音壁一般接电源、无大容量锂电，但需确认是否含纽扣电池）
- **待确认**：实际原产国、贸易方向（出口香港或转口内地）、额定功率、是否含电池
